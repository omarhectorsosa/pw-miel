
1. ¿Qué es IoT?
A) Una red de dispositivos conectados que transmiten y reciben datos
B) Un sistema operativo
C) Un lenguaje de programación
D) Una red social
Respuesta correcta: A

2. ¿Qué tecnología mejora la capacidad de IoT para manejar grandes volúmenes de datos?
A) 3G
B) Bluetooth
C) 5G
D) Infrarrojo
Respuesta correcta: C

3. ¿Cuál de los siguientes elementos es esencial para capturar datos en IoT?
A) Antenas parabólicas
B) Sensores
C) Baterías externas
D) Cámaras web
Respuesta correcta: B

4. ¿Qué etapa de IoT implica enviar datos a la nube o a otros dispositivos?
A) Procesar los datos
B) Actuar a partir de los datos
C) Compartir los datos
D) Analizar los datos
Respuesta correcta: C

5. ¿Qué tipo de red se usa comúnmente en hogares inteligentes?
A) FTP
B) Zigbee
C) SMTP
D) Ethernet industrial
Respuesta correcta: B

6. ¿Qué sector utiliza IoT para prevenir apagones mediante sensores?
A) Telesalud
B) Automóviles conectados
C) Redes inteligentes
D) Comercio minorista
Respuesta correcta: C

7. ¿Cuál es un ejemplo de uso de IoT en ciudades inteligentes?
A) Monitoreo de redes sociales
B) Detección de niveles de agua en desagües
C) Control de videojuegos
D) Edición de fotos
Respuesta correcta: B

8. ¿Qué tecnología en automóviles utiliza IoT para evitar colisiones?
A) Sistemas ADAS
B) Airbags
C) GPS básico
D) Limpiaparabrisas automáticos
Respuesta correcta: A

9. ¿Qué industria genera la mayor cantidad de datos de IoT?
A) Entretenimiento
B) IoT industrial (IIoT)
C) Educación
D) Agricultura
Respuesta correcta: B

10. ¿Qué innovación futura promete experiencias más inmersivas en IoT?
A) Teclados mecánicos
B) Audio 3D y realidad virtual
C) Televisión analógica
D) Radio FM
Respuesta correcta: B
